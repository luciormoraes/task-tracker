# Task-Tracker

## Usage:
```bash
  task-cli add "description"
  task-cli update <id> "description"
  task-cli delete <id>
  task-cli mark-in-progress <id>
  task-cli mark-done <id>
  task-cli list
  task-cli list todo
  task-cli list in-progress
  task-cli list done
```

## To build:
```bash
go build -o task-cli
```
